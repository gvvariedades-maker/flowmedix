## Nome do arquivo

```
[TELA]-[viewport]-[data].png
```

| Parte | Valores |
|-------|---------|
| TELA | `T1-landing`, `T2-login`, `T3-vitrine`, `T4-card`, `T5-player`, `T6-feedback`, `T7-dashboard`, `T8-conta`, `T9-neuroslides`, `T10-simulado`, `T11-caderno` |
| viewport | `desktop` (1280×800 ou 1440×900) · `mobile` (375×812) |
| data | `YYYY-MM-DD` opcional se múltiplas rodadas |

- Tema claro/escuro se aplicável
