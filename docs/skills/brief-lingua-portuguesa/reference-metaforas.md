## Interpretação e compreensão de texto

| Item | Valor |
|------|--------|
| **Metáfora** | Zonas do texto: **Dito** · **Inferido** · **Extrapolado** |
| **Erro espacial** | Marcar como “no texto” o que só o senso comum acrescenta |
| **concept_map** | 3–5 itens: tema do texto, comando (literal vs infere), pegadinha-âncora (extrapolação), estratégia |
| **Ícones** | `FileText`, `Quote`, `ScanSearch`, `AlertTriangle`, `Ban` |
| **golden_rule** | rows: “O texto diz” × “O candidato acha”; “Infere-se = pista necessária” |
| **logic_flow** | Ler comando → achar âncora no trecho → testar cada letra (dito?) → gabarito → “Em similares…” |
| **danger_zone** | Cada letra: por que parece / por que extrapola ou muda o sentido |
| **L3 genérico** | morphological + tap + compare |
| **L3 bespoke futuro** | `pt-text-zones` — spans no trecho + tap “está no texto?” |

## EXCETO / INCORRETA — metáfora arena

Independente do eixo gramatical:

1. `concept_map`: terreno da regra + “comando invertido”.
2. `logic_flow`: validar 4 como corretas → achar a exceção → letra.
3. `golden_rule`: regra violada pela exceção (portátil).
4. `danger_zone`: cada distrator = por que está **certo**; gabarito = por que é a exceção; + transferência.

Bespoke futuro: `pt-exceto-arena`.
