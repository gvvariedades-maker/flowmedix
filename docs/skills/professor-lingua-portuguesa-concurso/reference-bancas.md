# Referência — DNA das bancas (Língua Portuguesa)

Complemento da skill `professor-lingua-portuguesa-concurso`. Use para nomear padrões no `logic_flow` e na `danger_zone` — não copie texto genérico; adapte **à questão**.

---

## CEBRASPE / CESPE

| Aspecto | Padrão típico |
|---------|----------------|
| Formato | Certo/Errado (C/E) frequente; múltipla escolha em blocos mistos |
| Interpretação | **Literalidade** — “conforme o texto”, “segundo o autor” |
| Gramática | Itens isolados; julgamento binário rigoroso |
| Pegadinha P0 | Generalizar de 1 exemplo; inferir além do que o texto autoriza |
| No `logic_flow` | Passo 1: “O texto **diz** ou só **sugere**?” |
| Na `danger_zone` | “Parece lógico, mas o texto não afirma” |

**Transferência:** em CEBRASPE, quando em dúvida entre duas leituras, prefira a que **não acrescenta** informação.

---

## FGV

| Aspecto | Padrão típico |
|---------|----------------|
| Formato | Múltipla escolha; textos longos e densos |
| Interpretação | Coesão, coerência, **modalização** (pode/deve), ironia, ambiguidade controlada |
| Gramática | Integrada ao texto; reescrita e substituição de termos |
| Pegadinha P0 | Paráfrase que muda **nuance** (certeza, intensidade, causa) |
| No `logic_flow` | Compare conectivo, tempo verbal e foco antes de escolher |
| Na `danger_zone` | “Sinônimo aparente que altera o sentido global” |

**Transferência:** FGV cobra **leitura fina** — troque um advérbio e o gabarito muda.

---

## FCC

| Aspecto | Padrão típico |
|---------|----------------|
| Formato | Múltipla escolha clássica; texto + gramática no mesmo caderno |
| Interpretação | “Sem prejuízo de sentido”, “mantém o sentido original” |
| Gramática | Morfologia e sintaxe **escolares**; classificação de orações |
| Pegadinha P0 | Confundir adjunto adnominal × complemento nominal; termos “parecidos” |
| No `logic_flow` | Pergunta-teste sintática antes de olhar a letra |
| Na `danger_zone` | “Classificação que só muda o rótulo, não a função” (ou o inverso) |

**Transferência:** FCC gosta de **opção quase idêntica** com 1 palavra trocada.

---

## VUNESP

| Aspecto | Padrão típico |
|---------|----------------|
| Formato | Múltipla escolha; enunciados diretos |
| Interpretação | Compreensão global + detalhes; inferência **moderada** |
| Gramática | Concordância, regência, crase, pontuação em frases autônomas |
| Pegadinha P0 | Crase “decoreba”; concordância pelo termo mais próximo do verbo |
| No `logic_flow` | Localize núcleo do sujeito / teste de crase explícito |
| Na `danger_zone` | “Regra decorada que não vale neste contexto” |

**Transferência:** VUNESP premia **procedimento** (teste da crase, núcleo do sujeito).

---

## IBFC · IADES · Quadrix · AOCP · CONSULPLAN

| Aspecto | Padrão típico |
|---------|----------------|
| Formato | Múltipla escolha; EXCETO / INCORRETA comuns |
| Interpretação | Textos médios; questões objetivas |
| Gramática | Mistura regra + vocabulário |
| Pegadinha P0 | Distrator com **uma** palavra errada em frase quase perfeita |
| No `logic_flow` | Em EXCETO: valide 4 como corretas antes de achar a exceção |
| Na `danger_zone` | “Quase certa — falha em 1 detalhe” |

---

## CPCON · CESGRANRIO · bancas regionais

| Aspecto | Padrão típico |
|---------|----------------|
| Formato | Caderno objetivo; comando explícito |
| Interpretação | Direta; menos ambiguidade que FGV |
| Gramática | Regras de ensino médio; ortografia AO1990 |
| Pegadinha P0 | Candidato não relê o comando (CORRETA ↔ INCORRETA) |
| No `logic_flow` | Repita o comando em 1 step (“A banca pede EXCETO”) |
| Na `danger_zone` | “Alternativa correta para outro comando” |

---

## Matriz rápida — comando × estratégia

| Comando | Primeiro passo mental |
|---------|----------------------|
| **CORRETA / assinale a alternativa correta** | Elimine o que viola texto/regra |
| **INCORRETA / EXCETO** | Confirme que as outras **estão certas** |
| **Segundo o texto / de acordo com** | Só o que está **dito** ou **implícito necessário** |
| **Infere-se / deduz-se** | Conclusão **forçada** pelas pistas, não opinião |
| **Sem prejuízo / substituição** | Compare tempo, modo, conectivo, referente |
| **I, II, III + combinação** | Julgue cada item **isolado** antes de combinar |
| **C/E** | Um único erro → item errado |

## Como citar a banca nos slides (sem enrolar)

- `logic_flow` step: “Padrão FCC: teste adjunto × complemento antes da letra.”
- `danger_zone` item: “Em CEBRASPE, extrapolar 1 linha do texto costuma gerar C.”
- `golden_rule` row: “Regra portátil — vale em VUNESP/FCC: núcleo do sujeito = …”

Não invente estatística (“80% das provas…”). Nomeie o **mecanismo** da pegadinha.
