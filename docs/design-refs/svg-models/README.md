## Uso

1. Abrir 1–3 SVGs da família escolhida **antes** de desenhar.
2. Copiar gramática (viewBox, stroke, caps/joins, densidade) — não copiar paths literais em massa.
3. UI do app: preferir `lucide-react`; saúde: Health Icons; SVG custom só com skill `svg-quality`.

Guia Lucide: https://lucide.dev/contribute/icon-design-guide
