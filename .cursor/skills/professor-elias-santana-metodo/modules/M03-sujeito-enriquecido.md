## Aula 12 — Sujeito (teoria I)

| Campo | Conteúdo operacional |
|-------|----------------------|
| **Abertura** | Sujeito = termo sobre o qual se declara algo; enquadramento NGB / gramática de concurso |
| **Conceito** | Núcleo do sujeito + palavras que o expandem (adjuntos adnominais **dentro** do sujeito são permitidos) |
| **Expresso** | **Quem?** aparece na frase (nome/pronome) |
| **Posição** | **Anteposto** (antes do verbo) × **posposto** (depois do verbo) — posição **não** muda o tipo |
| **Exemplos-padrão (reescrever)** | Sujeito posposto: «Vivem em paz os homens de bem» → Quem vive? Os homens. / «Cabe às autoridades aprovar» → Quem cabe? As autoridades |
| **Obs. de prova** | Termo preposicionado **pode** integrar o sujeito (não confundir com complemento verbal) |
| **→ `concept_map`** | Verbo primeiro · Quem? · Expresso · Anteposto×posposto |
| **→ `golden_rule`** | row: Anteposto/posposto = posição, não tipo |

## Aula 13 — Sujeito II (tipos nucleares)

| Campo | Conteúdo operacional |
|-------|----------------------|
| **Taxonomia nível 2** | Simples (1 núcleo) · Composto (2+ núcleos coordenados) · Elíptico/desinencial · Indeterminado |
| **Simples** | Um núcleo: «O aluno estudou» |
| **Composto** | Dois núcleos: «João e Maria viajaram» |
| **Elíptico** | **Quem?** na desinência ou recuperável no texto/discurso (1ª/2ª pessoa; 3ª com referente) |
| **Indeterminado** | 3ª pessoa do plural **sem** referente recuperável |
| **Exemplos-padrão** | «Mentes tão bem» → tu/elíptico · «Estamos chocados» → nós/elíptico · «Disseram palavras» (sem referente) → indeterminado · «Eles disseram» → expresso |
| **Sequência Ouvi/Disseram** | Texto anterior recupera «os poetas» → elíptico, não indeterminado |
| **Obs.** | Sujeito antes do verbo = anteposto (classificação de posição à parte) |
| **→ `logic_flow` (piloto)** | ESTOU → 1ª pessoa → EU na desinência → E |
| **→ `danger_zone`** | B indeterminado vs E elíptico; D explícito vs elíptico |

**Equivalências didáticas (avisar 1× no slide):** elíptico = oculto = desinencial = implícito.

## Aula 14 — Sujeito III (sem sujeito × indeterminado × infinitivo)

| Campo | Conteúdo operacional |
|-------|----------------------|
| **Oração sem sujeito** | Verbo **impessoal** — não admite **Quem?** |
| **Indeterminado vs sem sujeito** | «Necessita-se de alimentos» → índice SE / passiva sintética (sem sujeito ou agente indeterminado conforme análise) · «É preciso confiar» → sem sujeito (impessoal) |
| **Sujeito em infinitivo** | «Chegou o tempo de o povo confiar» → sujeito = oração «o povo confiar» (não confundir todo infinitivo com sujeito) |
| **Chover — pegadinha clássica** | «Choveu» (fenômeno) = sem sujeito · «Choveu confete/granizo» (sentido literal) = pode ter sujeito |
| **Obs.** | Frase isolada na prova vs contexto de texto — recuperar referente no parágrafo |
| **→ `danger_zone`** | C sem sujeito × B indeterminado × E elíptico (três trilhos) |
| **→ `concept_map`** | Impessoal · Indeterminado · Referente no texto |

## Aula 15 — Sujeito IV (haver, fazer, fenômenos)

| Campo | Conteúdo operacional |
|-------|----------------------|
| **Haver existencial** | «Havia plantas» / «Houve acidentes» → sem sujeito (impessoal) |
| **Haver + dever/poder** | «Deve haver» / «Pode haver» → mesma lógica impessoal |
| **Haver temporal** | «Há oito meses» → impessoal (tempo decorrido) |
| **Fazer tempo/clima** | «Faz oito meses» · «Faz frio» → impessoal |
| **Obs. concordância** | «Haviam» → forma considerada incorreta na norma culta (usar «havia») |
| **Chover de novo** | Ideia **climática** reforça impessoal |
| **→ `golden_rule`** | rows: haver existencial · fazer tempo/clima · chover fenômeno |
| **→ handcraft** | Questão com HAVER/FAZER → testar impessoal antes de buscar Quem? |

## Aula 16 — Sujeito V (concordância do sujeito)

| Campo | Conteúdo operacional |
|-------|----------------------|
| **Foco** | Não é só classificar — é **com o que o verbo concorda** |
| **1 — Partitivas/coletivos** | «Um milhão de crianças» → núcleo partitivo |
| **2 — Percentuais/fracionários** | Porcentagem + núcleo |
| **3 — Quantidades aproximadas** | «Cerca de», «mais ou menos» |
| **4 — «Mais de um»** | Concordância no singular (regra de prova) |
| **5 — Palavras pluralizadas** | Casos em que o plural é só grafia |
| **6 — Sujeito composto** | Plural/singular conforme núcleos (sinônimos enfáticos, «tudo e flores»…) |
| **7 — Verbo SER** | Casos especiais de concordância |
| **8 — Topônimos** | «Estados Unidos» — determinante interno |
| **9 — Meio-dia e meia** | Expressão com concordância singular |
| **→ overlap M13** | Parte desta aula alimenta módulo Concordância especial |
| **→ `logic_flow`** | Identificar **núcleo do sujeito** antes da letra |

## Aula 17 — Sujeito Exercícios (padrão banca)

| Campo | Conteúdo operacional |
|-------|----------------------|
| **Ritmo** | Comando → eixo em 10s → eliminar impossíveis → gabarito → regra portátil |
| **Tipos cobrados** (amostra da aula) | Classificação de sujeito em trecho · Sujeito posposto («chegavam os poetas») · «Há aspectos» (impessoal) · «Esperamos que sim» (sujeito da oração subordinada) · Concordância com sujeito composto/partitivo · «Traz» concorda com núcleo · Reescrita estrutural |
| **Padrão CEBRASPE** | Afirmativas isoladas — julgar item a item |
| **Padrão FCC/FGV** | Trecho + alternativa — eliminar por motivo gramatical |
| **→ `logic_flow`** | 1 step por letra eliminada (reveal_mode tap) |
| **→ `danger_zone`** | Distrator que é gramaticalmente **correto** em outro contexto |

**Gabaritos da aula (referência interna):** 1-C, 2-E, 3-B, 4-A, 5-E, 6-C, 7-E, 8-C, 9-E, 10-C… (usar só para calibrar dificuldade; handcraft = questão do caderno AVANT)

## Slots NeuroSlides por tipo de questão (M03)

### Classificação (`family: conceito`)

| Slide | Slot |
|-------|------|
| `concept_map` | Mapa 4 nós (verbo, Quem?, expresso×oculto, pegadinha sem letra) |
| `logic_flow` | Comando → verbo → pergunta-teste → eliminação → gabarito → fixação |
| `golden_rule` | rows: elíptico / indeterminado / explícito / sem sujeito |
| `danger_zone` | 1 item por distrator — distinção fina da aula 13–14 |

### C/E ou VF (`family: certo_errado` / `vf`)

- Julgar **um critério por step** (concordância, tipo de sujeito, impessoal).
- Só combinar no penúltimo step.

### EXCETO / INCORRETA

- Distratores = classificações **corretas** em outro exemplo.
- Gabarito = única exceção.
