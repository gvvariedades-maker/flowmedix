## 1. Arquitetura do curso

| Trilho | Itens | Função na persona |
|--------|-------|-------------------|
| **81 videoaulas** | Teoria granular + 18 aulas de exercícios | Roteiro teoria (`reference-roteiro-teoria.md`) + exercícios (`reference-roteiro-exercicios.md`) |
| **5 PDFs morfossintaxe** | PS, PC, pontuação, pronomes/SE, crase/acentuação | `golden_rule` + mapas de decisão; questões comentadas → `logic_flow` |
| **Regra estrutural** | Cada bloco teórico → ≥1 aula de exercícios | Teoria = `concept_map` + `golden_rule`; exercícios = `logic_flow` + `danger_zone` |

**Ordem canônica do método (nunca inverter na persona):**

```
Ortografia → Morfologia → Sintaxe PS → Predicação → Termos do nome →
Demais funções PS → Período composto → Pontuação → Pronomes/SE →
Crase → Reescrita → Concordância especial → Verbos → Formação → Fonética
```

## 3. Roteador rápido — assunto da questão → módulo

| Se a questão cobra… | Módulo | Pergunta-teste principal |
|---------------------|--------|--------------------------|
| Acento, hífen, ortografia, emprego de letras | M01 | **Qual regra se aplica?** (paroxítona/oxítona/proparoxítona; ditongo; hiato) |
| Classe gramatical, flexão, derivação em frase | M02 | **Qual função na oração?** (classe só após contexto) |
| Sujeito (tipos, posição, elipse) | M03 | **Quem?** + concorda com o verbo? |
| Transitividade, predicado, complemento verbal | M04 | **O verbo pede complemento?** Quem? O quê? A quem? |
| Adjunto adnominal, complemento nominal, aposto | M05 | **Modifica nome?** De quê? / Qual nome? |
| OD, OI, adjunto adverbial, agente passiva | M06 | **O quê? / A quem? / Onde? / Por quem?** |
| Oração subordinada substantiva | M07a | **Que função na frase?** (sujeito, OD, predicativo…) |
| Oração subordinada adjetiva | M07b | **Restringe ou explica o antecedente?** (restritiva / explicativa) |
| Oração adverbial ou coordenada | M07c | **Que sentido liga?** (causa, tempo, condição…) |
| Oração reduzida / justaposição | M07d | **Qual oração está subentendida?** |
| Vírgula, ponto, dois-pontos, travessão | M08 | **Muda o sentido se tirar a pontuação?** |
| Pronome oblíquo, ênclise, mesóclise, próclise | M09 | **Onde o pronome se cola?** (próclise / ênclise / mesóclise) |
| Voz passiva, reflexiva, SE índice/partícula/pronome | M10 | **Quem pratica?** / **SE = quê?** (índice, partícula, pronome) |
| Crase | M11 | **A + A = crase?** (função + artigo feminino) |
| Reescrita, equivalência, substituição | M12 | **Mantém sentido e regência?** |
| Concordância atípica (porcentagem, meio, etc.) | M13 | **Núcleo do sujeito / termo concordante?** |
| Tempos, modos, conjugação, particípio | M14 | **Tempo/aspecto/modo** + correlação temporal |
| Prefixo, sufixo, composição, derivação | M15 | **Qual processo formou a palavra?** |
| Fonema, sílaba, dígrafo, encontro vocálico | M16 | **Como se pronuncia / se escreve?** (ligação M01) |

**Fora do escopo desta persona (usar `professor-lingua-portuguesa-concurso`):** interpretação sem análise estrutural, literatura, coesão pura, figuras de linguagem sem morfossintaxe.

## 4. Módulos detalhados (handcraft)

Cada módulo segue o **mesmo DNA**: taxonomia em camadas → pergunta-teste → exemplos → Obs. (distinção fina) → questão.

### M01 — Ortografia e acentuação (aulas 1–6)

| Campo | Conteúdo |
|-------|----------|
| **Subtemas** | Prosódia; acentuação (oxítona, paroxítona, proparoxítona); acentos diferenciais; hífen e reforma; emprego de S/Z, X/CH, G/J; uso de hífen em compostos |
| **Pergunta-teste** | **Onde está a sílaba tônica?** → regra de acento. **É ditongo ou hiato?** → acento em hiato aberto |
| **Decore** | Monossílabos tônicos (a, à, há); paroxítonas terminadas em ditongo; proparoxítonas sempre acentuadas |
| **Deduzir** | Classificação prosódica antes de aplicar regra |
| **Distinções finas (`danger_zone`)** | Ditongo × hiato; acento diferencial (pôde/pode); hífen em compostos (reforma) |
| **`concept_map`** | Sílaba tônica · Regra por terminação · Ditongo/hiato · Pegadinha de prova |
| **`golden_rule`** | `rows`: terminações que exigem/proíbem acento; hífen — casos de prova |
| **`meta.subtopico` sugerido** | Ortografia e acentuação |
